Comment se déroule le vrai examen

Pour situer l'entraînement dans le contexte réel de l'épreuve (source : certificat-voltaire.fr).

1. Dictée — 5 min
3 phrases simples, lues deux fois. Non notée, mais donne lieu à une réserve si trop d'erreurs.
2. Rédaction — 90 min
Résumé de 205 à 225 mots d'un texte argumentatif. L'orthographe n'y est pas notée : syntaxe, ponctuation, vocabulaire.
3. QCM Orthographe — 55 min
120 phrases (90 courantes + 30 littéraires), 3 segments soulignés (a, b, c) par phrase, 0 à 3 fautes possibles. Noté sur 1000.
4. QCU Vocabulaire — 30 min
100 mots professionnels, 4 propositions, une seule bonne réponse. Attention : une mauvaise réponse coûte plus cher qu'une absence de réponse.
